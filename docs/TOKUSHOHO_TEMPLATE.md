# 特定商取引法に基づく表記 — テンプレート

> 【 】内をあなたの情報で埋めて、店舗の固定ページに掲載してください。
> 通信販売を行う事業者には特定商取引法11条により表示義務があります。
> 個人の場合、BASE/STORES/Shopifyには住所・電話番号を非公開にして
> 請求があった場合に遅滞なく開示する運用が認められるケースがあります
> (各プラットフォームの最新ガイドを確認してください)。

---

## 特定商取引法に基づく表記

| 項目 | 内容 |
|---|---|
| 販売業者名 | 【氏名または法人名】 |
| 運営責任者 | 【氏名】 |
| 所在地 | 【住所】※請求があったら遅滞なく開示する場合はその旨を記載 |
| 電話番号 | 【電話番号】※同上 |
| メールアドレス | 【連絡先メールアドレス】 |
| 販売価格 | 各商品ページに表示(消費税込) |
| 商品代金以外の必要料金 | 送料【全国一律◯◯円 / 商品ページに表示】、銀行振込の場合は振込手数料 |
| 引渡時期 | ご注文確定後【◯〜◯営業日】以内に発送いたします(商品ページ記載の日数をご確認ください) |
| お支払い方法 | クレジットカード、【コンビニ決済・銀行振込・その他】 |
| お支払い時期 | ご注文時にお支払いが確定します |
| 返品・交換について | 商品到着後7日以内にご連絡ください。不良品・誤配送は当店負担で返品・交換いたします。お客様都合による返品は【可(送料お客様負担)/ 不可】です |
| 返品送料 | 不良品の場合は当店負担、お客様都合の場合はお客様負担 |

---

## 注意(muzaiko運用時のポイント)

- **引渡時期は仕入先リードタイムに余裕を持たせて記載する**こと。
  muzaikoの出品テンプレは仕入先の `shipping_days` をそのまま表示する設計。
  ここで盛ると特商法・景表法の両方でリスクになる。
- 海外仕入(AliExpress等)の場合は「海外倉庫より発送のため◯〜◯日程度」と明記する。
- 中古品を扱う場合は古物商許可が必要。本システムの想定は新品のみ。
