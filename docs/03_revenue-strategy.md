# 収益獲得・最大化の実践戦略(2026年7月版)

## 0. 戦略の基本思想

> 無在庫販売は「商品を売るビジネス」ではなく、**「勝ち商品と勝ち訴求を最速で見つける検証ビジネス」**。
> 在庫リスクゼロという利点を「検証回数の最大化」に全振りし、勝ちが確定したものだけに資本を寄せる。

収益の方程式: **売上 = トラフィック × CVR × 客単価、利益 = 売上 × 利益率 − 固定費**
- トラフィック: TikTokコンテンツ(無料)+ 勝ち商品への広告(有料)
- CVR: 2〜3%(平均)→ 3〜5%(上位)を信頼シグナル・UGC・独自コンテンツで狙う
- 利益率: モデル選定(下記)と手数料カテゴリ・関税で決まる。**常に純利益率で意思決定する**

## 1. モデル選定 — 3トラック構成

### トラックA: TikTok Shop クリエイターアフィリエイト【最優先・即開始】
- **内容:** 出店せず、TikTok Shopのアフィリエイトクリエイターとして商品紹介動画を投稿。報酬相場5〜20%。
- **なぜ今:** 日本のTikTok ShopはGMV月次1.5倍成長中・2026年末1,283億円規模見込み。GMVの70%がコンテンツ起点。在庫・発送・カスタマー対応・規約リスクすべてゼロで、実質的に最も純粋な「無在庫販売」。
- **役割:** キャッシュフローの立ち上げ + **どの商品が動画で売れるかの市場データ収集装置**(トラックBの商品リサーチを兼ねる)。
- **やること:** 1日1〜3本のショート動画を型で量産(悩み提起→実演→ビフォーアフター→CTA)。AIでスクリプト・編集を半自動化。報酬率とカテゴリ手数料(3〜15%)を見て商品を選ぶ。

### トラックB: 自社EC(Shopify)+ 規約適合サプライヤー【本命・資産化】
- **内容:** 自社ストアで販売し、国内サプライヤー直送/BUYMA型海外買付/(米国向けなら)米国内サプライヤーから発送。
- **なぜ:** 国内モールは無在庫禁止のため、規約リスクなしで無在庫をやれるのは自社EC。トラックAで検証済みの商品を持ち込むので勝率が高い。顧客リスト(メール/LINE)が資産になり、CAC0円のリピート売上を作れる。
- **禁じ手:** メルカリ・Amazon・楽天・Yahoo!への無在庫出品(アカウント停止・売上金没収リスク)。中国→米国の低単価直送(関税で利益消滅)。

### トラックC: 勝ち商品の在庫化・ブランド化【スケール段階】
- **内容:** 月間で安定して売れる上位2〜3商品をバルク仕入れ→国内3PL/モールのフルフィルメント納品(在庫ありモデルとしてAmazon等にも合法展開)→最終的にプライベートブランド化。
- **なぜ:** 無在庫のまま拡大すると配送品質・利益率で頭打ちになる。在庫化で原価と配送日数が下がり、モール展開で販路が広がり、PB化で利益率と参入障壁が上がる。動画#4(売上900万円の実体験)と2026年のCRO定石が示す共通の出口戦略。

## 2. 商品リサーチの運用ルール(動画#1・#5より)

1. **月次でリサーチをやり直す**(勝ち商品の寿命は数週間〜数ヶ月)。季節は1〜2ヶ月先行で仕込む。
2. **飽和検出:** 同じ商品の広告を3件以上見たら原則見送り。代わりに (a) 海外で売れ始めて日本未上陸のもの (b) 既存商品の別用途・別ターゲット提案 (c) レビュー欄の不満を解決する改良版・代替品 を探す。
3. **データ4軸で採点:** 需要(検索・販売数) / 競合数 / 価格帯(目安: 粗利2,000円以上または粗利率30%以上取れるか) / 季節性。
4. **AIワークフロー:** 競合のレビュー数百件をClaudeに読ませ「不満・未充足ニーズ・欲しい機能」を抽出→訴求アングルと商品選定に反映。
5. **テスト規律:** 1商品あたり小額(動画数本 or 広告5,000〜10,000円)で検証→CTR/CVR/粗利で判定→負けは即撤退、勝ちのみ増額。**同時に検証する商品数(テスト回数)が成果の先行指標**。

## 3. CVR最大化チェックリスト(動画#2 + 実証データより)

ストア/商品ページ公開前に全項目を満たす:

- [ ] 独自ドメイン・統一されたブランドデザイン
- [ ] 実在感のあるAboutページ(ブランドストーリー)・連絡先明示・明確な返品ポリシー
- [ ] メーカー説明文をベネフィット訴求に全面書き換え(AI生成→人間が事実確認)
- [ ] 写真付きレビュー/UGCを商品タイトル・価格の近くに配置(UGCでCVR最大+28%)
- [ ] 独自撮影 or 独自編集の商品画像・動画(メーカー画像の使い回し禁止)
- [ ] モバイル最適化: ファーストビューにカートボタン、折りたたみセクション、短文ブロック、表示速度
- [ ] 決済バッジ・主要決済手段(コンビニ払い/PayPay等、日本向けは特に)
- [ ] カゴ落ちメール/LINE自動化
- [ ] 特商法表記・景表法/薬機法チェック(法令面の信頼はCVRにも効く)

**目標値: CVR 2%未満=ページ改善優先、2〜3%=広告スケール可、3〜5%=上位水準。**

## 4. AI自動化スタック(動画#6・#7より)

| 工程 | AI活用 | 人間の役割 |
|---|---|---|
| 商品リサーチ | 競合レビュー分析、カテゴリブレスト、トレンド要約 | 最終選定の意思決定 |
| ストア構築 | Claude/Claude Codeでページ生成・コピー作成 | ブランドの世界観決定・事実確認 |
| 広告 | UGC風動画スクリプト、バリエーション量産 | 勝ちクリエイティブの判断・予算配分 |
| CS | FAQ自動応答、返信ドラフト | クレーム等の例外対応 |
| 運営 | サプライヤーMCP連携(在庫・注文・追跡の自動照会) | KPI監視と改善判断 |

原則: **AIに「自分の商品・マージン・配送条件・ポリシー」を構造化して渡す**(渡さない限りAIは知らない)。
このリポジトリ自体をその構造化データ置き場として育てる(商品マスタ、検証ログ、勝ちパターン集)。

## 5. 90日ロードマップ

### Day 1–30: 立ち上げ・検証開始(目標: 初売上、検証データ50本)
- TikTok Shopアフィリエイト登録、アカウントのジャンル決め(1ニッチに固定)
- ショート動画を30〜50本投稿(AIで台本量産、1本15分以内で作る型を確立)
- 並行してリサーチ運用ルール(§2)で商品候補20件をスコアリング
- 検証ログをつける: 商品×動画×再生数×クリック×成約×報酬

### Day 31–60: 勝ち筋特定・自社EC構築(目標: 月5〜10万円、動画#3の検証水準)
- 成約が出た商品カテゴリに投稿を集中、報酬率の高い商品へ入れ替え
- 上位商品でShopifyストア構築(CVRチェックリスト§3を全消化)
- 国内直送サプライヤー or BUYMA型仕入れ先を確保し、テスト注文で品質・納期を実測
- メール/LINEリスト取得開始(初回クーポン)

### Day 61–90: スケール(目標: 月20〜30万円、利益率で判断)
- 勝ち商品に広告投入(CVR 2%超を確認してから)。CPA < 粗利 を厳守
- 週次でKPIレビュー: 純利益、CVR、CPA、リピート率、キャッシュフロー(入金サイトと支払いのズレ)
- 月販が安定した上位1〜2商品はバルク仕入れ+3PL(トラックC)の損益分岐を試算
- 90日時点で「続ける商品/捨てる商品/在庫化する商品」を仕分け

## 6. KPIと撤退基準

| KPI | 健全ライン | アクション |
|---|---|---|
| 純利益率 | 15%以上 | 10%未満が2ヶ月続いたら商品・モデルを見直し |
| CVR | 2%以上 | 未満なら広告停止しページ改善 |
| CPA | 粗利の70%以下 | 超えたらクリエイティブ差し替え、3回失敗で商品撤退 |
| 返品・クレーム率 | 5%未満 | 超えたらサプライヤー変更(信用毀損は致命傷) |
| テスト数 | 週5商品 or 週15動画 | 下回る週を作らない(検証量=成果の先行指標) |

## 7. リスク管理(動画#4の教訓 + 規制環境)

1. **規約リスク:** 国内モールへの無在庫出品は絶対にしない。プラットフォーム依存を避け、自社EC+顧客リストを資産の中心に置く。
2. **関税リスク:** 米国向けをやる場合はデミニミス撤廃後の設計(米国内サプライヤー/高単価/バルク+3PL)以外は組まない。
3. **キャッシュフロー:** 広告費・仕入れ先行を前提に、月商の1.5ヶ月分の運転資金を確保してからスケールする。
4. **法令:** 特商法表記、景表法(AI生成コピーの誇大表現チェック)、薬機法(美容健康系)、古物営業法(中古)、商標(ブランド品)。
5. **単一依存の排除:** 1商品・1媒体・1サプライヤーに売上の50%以上を依存させない。
