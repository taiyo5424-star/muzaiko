## 2. 2026年7月時点の環境検証(裏取り)

### 追い風 ✅

- **歴史的円安 = 輸出型の構造的優位**。ドル円は2026年7月に一時162円台と
  [約39年半ぶりの円安水準](https://www.smd-am.co.jp/market/ichikawa/2026/07/irepo260702/)。
  年末165円予想もあり([大和総研](https://www.dir.co.jp/report/column/20260708_012450.html))、
  日本から売る(輸出)側は価格競争力が高い。**逆に海外から仕入れて日本で売るBUYMA(動画5)や
  中国輸入(動画6)は仕入コスト高の逆風**。
- **Shopeeの無在庫はプレオーダー機能で正規に可能**。決済完了から発送までを最大10日まで
  延長できる([しょっぴーの達人の規約解説](https://note.com/shopee_tatsujin/n/n549867283206)、
  [Wise解説](https://wise.com/jp/blog/how-to-sell-on-shopee))。動画3・9の主張は現行規約と整合。
- **売れ筋は「推し活コレクター消費」**。BEENOS 2025年版の越境ECランキングは
  [1位トレカ・2位ホビー・3位アニメグッズ](https://netshop.impress.co.jp/n/2026/03/03/15670)。
  ぬいぐるみ・マスコット・キーホルダーがけん引し、ちいかわ(東アジア)・サンリオ(北米)・
  ポケモン(欧州)と[地域別に人気IPが異なる](https://netshop.impress.co.jp/n/2026/04/09/15886)。
  海外ユーザーの[87%がアニメグッズの越境EC購入経験あり](https://netshop.impress.co.jp/n/2026/05/27/16133)。
  **動画2(シルバニア)の「ニッチ玩具×コレクター需要」はデータで一般化できる**。
  2026年はポケモン30周年で日本限定アイテム需要の拡大見込み
  ([eBay輸出2026年トレンド](https://ebay-marketing-tool.com/ebay-export-recommendation/))。

### 逆風・条件付き ⚠️

- **米国向けはデミニミス撤廃(2025年8月)+一律10%関税**。
  [800ドル以下の免税が廃止され](https://www.busoken.com/blog/ebay/ebay-customs-duty)、
  [2026年2月から一律10%の輸入賦課金](https://exponential-ebay-tool.com/blog/research/ebay-news-2026-04-us-tariff-update/)。
  eBayは[関税込み(DDP)販売の義務化へ](https://ebay-marketing-tool.com/ebay-export-recommendation/)。
  動画7のeBay輸出は依然有効だが、**関税を織り込んだ価格設計が必須**になった。
  一方、**東南アジア(Shopee)にはこの関税変更が無い**ため相対優位。
- **Amazon無在庫(動画1)は規約の線引きが厳格**。
  [他小売(AliExpress等)からの直送は明確に禁止](https://www.autods.com/blog/suppliers-marketplaces/amazon-dropshipping-policy/)。
  自分がseller of recordとなり卸・メーカーから直送する形のみ可
  ([Amazon公式](https://sell.amazon.com/learn/what-is-dropshipping))。やるなら国内卸直送型のみ。
- **BUYMA(動画5)は競争激化+円安逆風**。
  [ライバル増でリサーチ困難化、仕入ルート確保が勝負](https://kigyo18.net/buyma-kigyo-seikou.html)。
  円安で仕入コストも上昇。現環境では優先度を下げる。
- **Shopeeの規律要件**: 発送期限(DTS)超過・在庫切れキャンセルはペナルティで検索順位低下
  ([出品ガイド](https://ebay-marketing-tool.com/shopee-export/))。
  新規店は出品数上限1,000(台湾500)。→ **在庫同期の自動化(sync)が生命線**。

## 3. 戦略(優先順位)

1. **主戦場 = Shopee輸出無在庫**(動画3・8・9 × 円安 × 関税回避)
   - プレオーダー設定(発送期限≦10日)で無在庫を正規運用
   - シンガポール→マレーシア→台湾の順で市場追加(動画9の「完璧を目指さず段階拡大」)
   - リードタイム10日超の商品は扱わない(DTSペナルティ回避)
2. **商品選定 = 推し活・コレクターカテゴリ優先**(動画2の一般化)
   - トレカ/ホビー/アニメ/ぬいぐるみ/限定品をスコアで優遇
   - 地域別IP: 東アジア=ちいかわ、北米=サンリオ、欧州=ポケモン
3. **eBay輸出は高単価×DDP価格設計で継続**(動画7)
   - 関税バッファ10%を価格に織り込む。中価格帯($21-200)は影響限定的
4. **Amazon無在庫は国内卸直送型のみ**(動画1) — 規約準拠が絶対条件
5. **BUYMA・中国輸入は現環境では見送り**(円安逆風のため。円高転換で再評価)

## 4. muzaiko への実装(本コミット)

| 動画の教え | 実装 |
|---|---|
| Shopee輸出無在庫(動画3・9) | `shopee_export` チャネル追加: 一括アップロードCSV生成、プレオーダー自動判定(リードタイム>2日)、発送期限10日上限の警告 |
| 出品自動化ツール(動画8) | 同上(クロセル相当の出品データ自動生成を無料で内製) |
| ニッチ玩具・推し活(動画2) | リサーチスコアに**トレンド加点20点**(トレカ/ホビー/アニメ等のキーワード一致)。サンプルフィードにも該当商品を追加 |
| eBay米国向けDDP(動画7+関税環境) | `pricing.tariff_buffer_rate` 追加: 関税分を価格に自動で織り込む |
| 輸出の通貨対応 | `channel.currency` / `channel.fx_rate` で現地通貨換算 |
| 売り越し防止の徹底 | sync がリードタイムも追従(DTS判定を最新化) |

設定例は `config.example.json` の `_examples`(Shopeeシンガポール / eBay米国DDP)を参照。
