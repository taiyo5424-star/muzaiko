# 2026年7月時点の市場環境・規制・トレンド

戦略の前提となる「今の環境」を出典付きで整理する。動画の主張のうち、現時点でも有効なもの/既に前提が変わったものを判別するための土台。

## 1. 【最重要】米国デミニミス(800ドル免税)の撤廃 — 従来型モデルの終焉

- 2025年5月2日に中国・香港発の免税を停止、**2025年8月29日に全世界発へ拡大**。2026年2月のホワイトハウス布告で停止継続が確認され、復活の見通しなし。
- 従来800ドル未満は無税で通関できた小口直送パッケージに、最大145%の関税+通関コストが発生。**中国→米国消費者への直送ドロップシッピングの利益率は15〜20%から1桁台に圧縮**され、低単価商品では「通関コスト>商品原価」になるケースも。
- 生き残りパターン(米国向けに売る場合):
  - **米国内サプライヤーからの国内直送**(配送も7〜15日→2〜3日に短縮)
  - **コンテナでバルク輸入→米国内3PLから出荷**(パッケージ単位の関税処理を回避)
  - **高単価商品($200+)** で関税コストをマージンで吸収
  - リピート顧客を持つブランド型ストア

## 2. 【日本の最大トレンド】TikTok Shop の急成長

- 2025年の日本ローンチ後、最初の半年で累計GMV約150億円、月次成長率約1.5倍ペース。**2026年末には年間GMV約1,283億円規模に到達する見込み**。
- 国内アクティブ出店者5万社超、登録クリエイター20万人超。**GMVの約70%がショート動画・LIVE配信起点の「コンテンツドリブン購買」**。
- **クリエイターアフィリエイト**: セラーが商品ごとに報酬率を設定(公式上1〜80%、相場5〜20%)。クリエイター側は在庫・梱包・発送リスクなしで報酬を得られるため、「無在庫の検証型クリエイター」としての個人参入が急増中。
- **2026年5月11日からセラー販売手数料が一律7%→カテゴリ別体系(海外実績で3〜15%幅)に移行済み**。カテゴリ選定が利益率に直結するようになった。

## 3. 【規約リスク】国内プラットフォームの無在庫出品規制

- **禁止(取り締まり厳格化中):** メルカリ(売上金没収+アカウント停止の実例)、Amazon、楽天、Yahoo!ショッピング。年々検出と処分が強化されている。
- **許容:** BUYMA(受注後の海外買付が公式に前提のモデル)、Shopify等の自社EC(自社サイトなら規約制約なし。ただし特商法等の法令遵守は必須)。
- 「自分で仕入れて倉庫・フルフィルメントに納品する」方式(実質在庫あり)は各モールで認められており、勝ち商品確定後の移行先として有効。

### 日本で販売する際の法令チェックリスト

- **特定商取引法**: 自社ECでは事業者情報の表記義務
- **景品表示法**: 誇大広告・不当な二重価格表示の禁止(AI生成コピーも対象)
- **薬機法**: 化粧品・健康グッズの効能表現規制
- **古物営業法**: 中古品を扱う場合は古物商許可
- **商標・並行輸入**: ブランド品は真贋・商標権に注意(BUYMA型で特に重要)

## 4. 【運営の勝ち筋】AI活用の主流化

- AIはリサーチ・価格設定・コピー・広告・CS・注文処理まで浸透。ChatGPT/Claudeに条件を与えた商品カテゴリのブレスト、**競合レビューを読み込ませた不満・未充足ニーズの抽出**が定番ワークフロー化。
- Claude+MCP(例: ZendropのMCPサーバー)で、商品検索・配送確認・注文状況・分析・フルフィルメントのトリガーまで自然言語で操作する構成が登場。ストア構築→リサーチ→AI UGC広告→フルフィルメント自動化までAI主導で完結する事例も。
- 商品説明(見出し+ベネフィット箇条書き+SEO文)はAIで30秒で生成可能。**制約は「自分の商品・マージン・配送・ポリシー情報を与えない限りAIは知らない」こと** = 自社データの構造化が競争力になる。

## 5. 【CVRベンチマーク】CROの現在地

- ドロップシッピングストアのCVRは**平均2〜3%、上位で3〜5%**。
- 効果が実証されている施策:
  - 信頼シグナル: 独自ドメイン、実在感のあるAboutページ、連絡先明示、写真付きレビュー、セキュア決済バッジ、明確な返品ポリシー
  - **UGC(写真・動画レビュー)はCVRを最大+28%**。評価と件数は商品タイトル/価格の近くに配置
  - メーカー説明文の「機能訴求」を「ベネフィット訴求」に書き換え
  - モバイル最適化: カートボタンを早期に可視化、折りたたみセクション・箇条書き・短文ブロック
- スケールの定石: 上位2〜3商品を特定→独自撮影・より良いサプライヤーに再投資→メールリスト構築(CAC0円のリピート)→勝ち商品に広告集中→**最終的にプライベートブランド化**で利益率と防御力を確保。
