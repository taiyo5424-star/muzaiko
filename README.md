## 結論サマリー(2026年7月時点)

1. **中国直送→米国向けの従来型ドロップシッピングは構造的に終了。** 米国のデミニミス(800ドル免税)撤廃により利益率が1桁台に圧縮された。やるなら「米国内サプライヤー」「高単価($200+)」「バルク輸入+3PL」のいずれか。
2. **日本市場の最有力は TikTok Shop。** 2025年ローンチ後、2026年末に年間GMV約1,283億円規模へ成長見込み。GMVの約70%がショート動画・LIVE起点。クリエイターアフィリエイト(報酬相場5〜20%)は在庫・発送リスクゼロの実質的な無在庫モデルとして最も参入障壁が低い。
3. **国内モールでの無在庫出品は原則NG。** メルカリ・Amazon・楽天・Yahoo!は規約で禁止かつ取り締まり厳格化中。合法的にやるなら「BUYMA」「Shopify等の自社EC+国内サプライヤー直送」「TikTok Shopアフィリエイト」。
4. **差別化の主戦場は AI 活用と CRO。** 商品リサーチ・LP作成・UGC広告・カスタマー対応をAIで自動化し、CVR 2〜3%(平均)→3〜5%(上位)を目指す。信頼シグナルとUGCでCVRは最大+28%。
5. **「商品を売る」より「勝ち商品を早く見つけて検証を回す」ゲーム。** 飽和商品を避け、未開拓ニッチ×独自アングルで小さくテスト→勝ち商品に集中投資→将来的にプライベートブランド化が王道ルート。
