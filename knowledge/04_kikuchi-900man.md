# Kikuchi Tatsuya「【売上900万円】ドロップシッピングの体験談を本音ではなします。」学習ノート

- 動画: https://youtu.be/WwF1su2B7c0 (Kikuchi Tatsuya / ecom academy)
- 出典: 日本語自動字幕の全文読解(短編動画)
- **注記: 具体的数値の多くは画面表示依存で字幕に含まれない。明言された数値は「売上900万円」のみで、利益・広告費・費用は非開示。動画はスクール勧誘色が強く、内容はほぼ全面ポジティブ**

## 話者プロフィール

- 達也、23歳、日本在住。ドロップシッピング歴1年未満
- 人生の半分をブラジルで過ごしポルトガル語話者 → その語学力で海外メンター(世界向け無在庫販売の講師)に師事
- 現在はそのスクールの講師も務める(=動画はスクール導線)

## 売上900万円の内訳(字幕から判明する範囲)

- **商品: サイドテーブル(単一商品)**
- **期間: 30日間(約1ヶ月)**
- 手法: 無在庫販売(「売れてから仕入れる」構造。発送・在庫管理はサプライヤーが代行)
- 販売先の国・プラットフォーム・広告手法は字幕内で非明言(文脈上は越境販売)
- **900万円は「売上」であって利益ではない。** 利益率・広告費は非開示

## 語られたメリット

1. 知識ゼロでも始められる(ただし「教えてもらう・助けてもらうことが大事」)
2. 無在庫なので在庫リスクがない
3. 在庫管理・発送作業が不要
4. 再現性がある仕組み(※本人とメンターの体験談ベースの主張で根拠データなし)

## 実務的な持ち帰りポイント(3点)

1. **売上と利益を区別する**: 派手な売上数字に惑わされず、広告費・仕入・手数料・返品を引いた純利益で事業を評価する
2. **顧客体験(購入後の満足度)が最重要**: 「商品を買った後にお客様が満足して終われるか」— 配送品質・アフター対応がリピート・評価・アカウント健全性に直結(本人が販売中に最も実感したこと)
3. **単一の検証済み商品に集中**: 900万円は多商品ではなくサイドテーブル1商品。勝ち商品を見つけたらそこにスケールを集中する

## 批判的注意点(資料として)

- 再現に必要な具体ノウハウ(商品選定法、広告費、価格設定、利益額)は動画内でほぼゼロ
- 実質的な目的はスクールへの導線+チャンネル登録促進
- 「安全」「再現性がある」の主張に根拠データの提示はない
- **教訓: 体験談系コンテンツからは「数字の派手さ」ではなく「失敗回避策と原則」だけを抜き取る**
