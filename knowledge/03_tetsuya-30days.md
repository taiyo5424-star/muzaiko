- 動画: https://youtu.be/3n7GOKqZ1kQ (TETSUYA)
- 出典: 日本語自動字幕の全文読解
- **重要注記: 取得できた字幕は動画前半(リサーチ〜ショップ公開)まで。30日間の実売結果(売上・利益)は字幕に含まれておらず、最終結果は本人視聴での補完が必要**

## 実行された手順(時系列)

全体工程の宣言: メールアドレス作成 → ECサイト作成 → SNS開設 → 出品 → 動画撮影 → 広告出稿

1. **商品リサーチ**: 分析ツール(米国TikTok Shop系。Kalodata等と推定)で**アメリカ市場の過去30日データ**を確認し、商品2つを選定
2. **ChatGPTで売れ行き検証**: 専用プロンプトテンプレートに商品名/リンク/説明を貼って分析(商品1「可能性が高い」、商品2「市場ニーズが存在し成長傾向」)
3. **仕入原価の確認**: 中国仕入サイト(元建て表記。1688系と推定)で実売価格を検索
4. **ブランド名決定**: ChatGPTに依頼→初案は不発→「一言で終わる・覚えやすい」と条件を具体化して再生成→「エアラックス」に決定
5. **コンセプト決定**: 候補2案をChatGPTに「人が購入したくなるコンセプトを心理学的にどちらがいいか」と比較させ「ケーブルからの解放、もっと自由なドライブへ」に決定
6. **ECサイト構築・出品**: 商品名・説明・価格・在庫を設定。仕入元画像は背景の写り込みがあり**PhotoRoom系アプリで背景除去・白背景化**
7. **特定商取引法に基づく表記を記載**(「やらないとかなりトラブルになる」と強調)
8. **ショップ公開** →(以降のSNS投稿・広告出稿・結果は字幕範囲外)

## 収益獲得に活かせる教訓

1. **タイムマシン型リサーチ**: 米国で既に売れているものを日本に持ってくる。ゼロから当てにいかない
2. **複合指標で選定**: 市場規模 / 成長率 / 件数 / 単価 / **クリエイターCVR(動画経由で売れやすいか)**。動画で売るなら成長率とクリエイターCVRを軸に(商品2: 452% / 74.53%)
3. **参入前に粗利を数字で確定**: 実原価と市場平均価格の差(この例では1個2,000円超)を見てから参入。値付け余地の目線も持つ
4. **ChatGPTは壁打ちに使う**: 出力が微妙なら条件を具体化して再生成。コンセプトは「心理学的にどちらが購入意欲を高めるか」で比較させる
5. **コンセプトは「広告動画の冒頭フックが撮れるか」で選ぶ**: 「ケーブルが絡まってうざい」という共感シーンが撮れることが決め手 = コンセプトはクリエイティブの設計図
6. **関連商品で1ブランド化**: 同ジャンル複数商品を束ねて一貫性とクロスセルを狙う
7. **ECは画像が命**: 仕入元画像は必ず背景除去・白背景化
8. **特商法表記は必須**(省略するとトラブル)
9. **売れているクリエイターの動画を参考にクリエイティブを作る**
